## 1. CONTEXTO E OBJETIVO

O Experimento 2 foi projetado para demonstrar empiricamente a Lei dos Grandes 
Números (LGN), um dos teoremas fundamentais da teoria das probabilidades. A LGN 
estabelece que, sob certas condições, a média aritmética de uma sequência de 
variáveis aleatórias independentes e identicamente distribuídas converge em 
probabilidade para a esperança matemática dessas variáveis quando o número de 
observações tende ao infinito.

Matematicamente: Para X₁, X₂, ..., Xₙ i.i.d. com E[Xᵢ] = μ,
    lim(n→∞) P(|X̄ₙ - μ| > ε) = 0, para qualquer ε > 0

Onde X̄ₙ = (X₁ + X₂ + ... + Xₙ)/n é a média amostral.

No contexto deste simulador:
- Xᵢ representa o lucro na i-ésima rodada
- μ = E[X] = -0,1600 créditos (esperança teórica)
- Cada rodada é independente das anteriores
- A distribuição de probabilidade é idêntica em todas as rodadas

## 5. DISCUSSÃO CRÍTICA E LIMITAÇÕES

### 5.1 Por Que a Convergência Não É Perfeita?

Observamos que em 10.000 rodadas, nenhuma sequência atingiu exatamente E[X] = 
-0,1600. As razões são:

1. **Natureza Assintótica da LGN:**
   A LGN é um resultado sobre o limite quando n → ∞. Com n finito (mesmo 10.000), 
   sempre haverá algum desvio. Para garantir |X̄ₙ - E[X]| < 0,01 com alta 
   probabilidade, seriam necessárias dezenas ou centenas de milhares de rodadas.

2. **Alta Variância dos Lucros:**
   O desvio padrão teórico de X é aproximadamente 5,28 créditos, muito maior 
   que |E[X]| = 0,16. Esta alta variância relativa significa que flutuações 
   significativas são esperadas mesmo com n grande.

3. **Pequeno Número de Sequências:**
   Com apenas 3 sequências, observamos apenas 3 realizações do processo 
   estocástico. Para conclusões mais robustas, idealmente teríamos dezenas ou 
   centenas de sequências independentes.

4. **Eventos Raros Ainda Ocorrem:**
   Mesmo com probabilidade 0,8% cada, os prêmios grandes (9, 14, 24, 49) 
   ocorrem. Uma sequência que por acaso teve mais ou menos desses eventos 
   apresentará desvio mais significativo.


### 5.2 Convergência Não-Monotônica

É crucial entender que a LGN **não garante** que |X̄ₙ₊₁ - E[X]| < |X̄ₙ - E[X]|. 
A convergência é em probabilidade, significando que:

    P(|X̄ₙ - E[X]| > ε) → 0 quando n → ∞

Mas trajetórias individuais podem ter flutuações locais. O que vemos nas 
sequências 10 e 123456 (piora de 5.000 para 10.000) é perfeitamente compatível 
com a LGN.

Para garantir convergência monotônica com alta probabilidade, seria necessário 
usar estimadores alternativos ou técnicas de redução de variância.

## 7. COMPARAÇÃO COM TEORIA

### 7.1 Erro Padrão Teórico

O erro padrão da média é dado por: SE(X̄ₙ) = σ / √n

Onde σ ≈ 5,28 créditos (desvio padrão teórico de X).

Para n = 10.000: SE(X̄₁₀₀₀₀) = 5,28 / √10.000 = 0,0528 créditos

Portanto, esperamos que X̄₁₀₀₀₀ esteja aproximadamente dentro de ±2 SE de E[X] 
com 95% de probabilidade:

Intervalo esperado: -0,1600 ± 2(0,0528) = [-0,2656, -0,0544]

**Verificação com os dados:**
- Sequência 10:     -0,0960 ✓ (dentro do intervalo)
- Sequência 2026:   -0,1315 ✓ (dentro do intervalo)  
- Sequência 123456: -0,2215 ✓ (dentro do intervalo)

**CONCLUSÃO:** Todas as três médias observadas estão dentro do intervalo 
esperado pela teoria estatística. Os "desvios" observados não são anomalias, 
mas manifestações normais da variabilidade amostral.


### 7.2 Taxa de Convergência

A LGN forte estabelece que X̄ₙ → E[X] quase certamente. O Teorema Central do 
Limite complementa isso, mostrando que:

    √n (X̄ₙ - E[X]) →ᵈ N(0, σ²)

Isto implica que o erro esperado diminui com ordem O(1/√n). Para reduzir o 
erro pela metade, é necessário quadruplicar o número de rodadas.

**Verificação empírica:**
- n = 1.000: erro médio = 0,0850
- n = 5.000: erro médio = 0,0223 (redução de 74%)
- Previsão teórica: 0,0850 / √5 = 0,0380

A redução observada (74%) foi maior que a prevista (√5 ≈ 2,24, ou 55% de 
redução), sugerindo que tivemos "sorte" em obter convergência mais rápida 
que o esperado em 5.000 rodadas.

## 10. REFERÊNCIAS TEÓRICAS

Os resultados observados são compatíveis com:

1. **Lei Fraca dos Grandes Números (Khinchin, 1928):**
   Para variáveis i.i.d. com E[X] e Var(X) finitos, X̄ₙ →ᵖ E[X]

2. **Lei Forte dos Grandes Números (Kolmogorov, 1933):**
   Para variáveis i.i.d. com E[X] finito, X̄ₙ → E[X] quase certamente

3. **Teorema Central do Limite:**
   √n(X̄ₙ - E[X]) →ᵈ N(0, σ²), que explica a taxa de convergência O(1/√n)

4. **Desigualdade de Chebyshev:**
   P(|X̄ₙ - E[X]| ≥ ε) ≤ σ²/(nε²), que fornece limites superiores para a 
   probabilidade de desvio
