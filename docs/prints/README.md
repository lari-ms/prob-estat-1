## 🎯 Como capturar:

1. **Execute o comando** no terminal
2. **Pressione `Win + Shift + S`** para captura seletiva
3. **Selecione a área** relevante
4. **Abra Paint** e cole (`Ctrl + V`)
5. **Salve nesta pasta** com o nome indicado acima
